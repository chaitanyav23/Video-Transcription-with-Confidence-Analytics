## Rewritten Imports

All copied stage scripts were changed to import the local shared helper:

```python
from common import ...
```

The shared helper module was renamed to `common.py`. No algorithm bodies were rewritten.

## Rewritten Paths

- `run_phase20.py` now uses `phase20_standalone` as `PROJECT_ROOT` and subprocess working directory.
- `scripts/common.py` now sets `PROJECT_ROOT` to the standalone root and uses `.cache/` inside that folder.
- `scripts/step10_compare_phase19.py` now reads `phase19_reference/` inside the standalone folder.
- Copied JSON, log, manifest, and report artifacts were rewritten so stored paths point at the standalone project.

## Files Intentionally Not Copied

- Phase 1 through Phase 18 experiment directories: not imported or read by Phase 20.
- Phase 19 source code and reports: not needed for execution; only Phase 19 grounding and metrics artifacts are read by the comparison stage.
- Repository-level reports unrelated to Phase 20 execution.
- Python bytecode, notebook checkpoints, and cache directories.
- Secret `.env` files: `.env.example` is provided instead. A user must provide `HF_TOKEN` for model download/regeneration.
- Full `.cache/` model cache: reproducibility is handled by `download_models.py`.
